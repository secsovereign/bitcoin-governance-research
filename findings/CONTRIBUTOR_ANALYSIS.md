## Methodology

- **Contributor**: Anyone with GitHub activity on `bitcoin/bitcoin` (PR author, commenter, reviewer, issue creator, issue commenter). Delving / Bitcointalk / list-only names are **not** in these totals — see `GOVERNANCE_FRAMES.md`.
- **Active**: Activity within 365 days of the last observed GitHub event in this dump (not calendar today)
- **Exited**: No activity in that same 365-day window
- **Author**: Authored at least 1 PR
- **Participant**: Never authored a PR
- **High-Quality**: 50%+ PR merge rate (authors only)
- **One-Time**: Exactly 1 total activity
